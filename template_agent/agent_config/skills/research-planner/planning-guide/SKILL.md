# Research Planning Guide

## Complexity Assessment

### SIMPLE (1-2 sub-questions)
- Single topic with a clear answer
- Factual comparison between 2 items
- Current state of one specific technology or trend
- Example: "How does React Server Components work?"

### MODERATE (3-5 sub-questions)
- Topic with multiple dimensions (technical, business, social)
- Comparison between 3+ alternatives
- Topic requiring historical context + current state + future outlook
- Example: "Compare Kubernetes vs serverless for microservices deployment"

### COMPLEX (5-8 sub-questions)
- Broad industry trend with many stakeholders
- Multi-domain topic (technology + regulation + market)
- Strategic analysis requiring competitive landscape
- Example: "How is AI transforming healthcare diagnostics globally?"

## Sub-Question Generation Rules

1. **Non-overlapping**: Each sub-question should target a distinct facet. No redundancy.
2. **Specific**: "What are the performance benchmarks of X vs Y?" not "Tell me about X."
3. **Searchable**: Each sub-question should be answerable through web search.
4. **Ordered**: Arrange from foundational (definitions, background) to advanced (analysis, predictions).
5. **Balanced**: Cover multiple perspectives — technical, practical, critical.

## Good Sub-Question Patterns
- **Definition/Background**: "What is [X] and what problem does it solve?"
- **Current State**: "What is the current adoption rate / market size of [X]?"
- **Comparison**: "How does [X] compare to [Y] in terms of [criteria]?"
- **Pros/Cons**: "What are the main advantages and limitations of [X]?"
- **Use Cases**: "What are real-world implementations of [X]?"
- **Future Outlook**: "What trends or predictions exist for [X] in the next 2-3 years?"
- **Expert Opinion**: "What do industry leaders and researchers say about [X]?"

## Search Query Formulation
For each sub-question, suggest 2-3 search queries:
- One broad query for overview
- One specific query for data/benchmarks
- One query targeting expert opinions or recent analysis

Example:
```
Sub-question: "What are the performance characteristics of Rust vs Go for backend services?"
Search queries:
  - "Rust vs Go backend performance benchmarks 2025"
  - "Rust Go comparison latency throughput microservices"
  - "Rust vs Go which to choose backend expert analysis"
```
